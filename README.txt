《梦回之镜》第1场轻量网页试跑
================================

在线地址
--------
https://383158353-sys.github.io/menghui-demo/

怎么打开（本地）
--------
1. 用浏览器直接打开本目录下的 index.html
   （双击，或拖进 Chrome / Edge / Firefox；无需联网）
2. 点「开始」进入寝室闪回
3. 点击对话框，或按空格 / Enter，推进下一句

画面规格
--------
舞台固定 3:2 比例，适配电脑屏（尽量占满视口且不裁切）。
立绘为 3:2 厚涂二次元半身 PNG（透明底），底部居中显示。

覆盖到哪一句
------------
仅第1场：内景 · 大学寝室 · 傍晚（闪回 / 暖色调）
从进门惊喜生日 → 切至酒后约定 → 演到：
  睿睿：「你30岁，那就是2034年的3月28日，行。」
  以及后续「一辈子发不了财」发誓整段笑场结束。
重庆空镜、片头名单、第2场起均未包含。

人物立绘切换
------------
李沫 / 孟子玥 / 睿睿：说话人名标签切换时，对应立绘高亮放大，其余压暗。
旁白无名字标签，立绘按剧情进出。
立绘为透明 PNG，本地 file:// 即可显示。
